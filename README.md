# Tennis Practice Log

## Overview

Tennis Practice Log is a simple web application that allows tennis players to record and organize their practice sessions. This project was built as my first web development project while learning HTML, CSS, JavaScript, Git, and GitHub.

## Features

- Log a new practice session
- Record the practice date
- Record the duration of practice
- Write notes about each session
- Select multiple practice categories
- Edit existing practice sessions
- Automatically save practice sessions using browser Local Storage

## Technologies

- HTML
- CSS
- JavaScript
- Git
- GitHub

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Start logging your practice sessions.
